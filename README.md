# Anand & Disha · Wedding website

This is a static GitHub Pages site. The RSVP section embeds the published Google Form. Responses are available in Google Forms and in the linked Google Sheet if you set one up.

## Publish on GitHub Pages

1. Create a public repository on GitHub or open your existing wedding site repository.
2. Upload the extracted `index.html`, `styles.css`, and `site.js` directly to the root of the `main` branch and commit them.
3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. Open the published link shown under **Settings → Pages** in a private browsing window. Scroll to RSVP, submit a labeled test reply, and verify it appears in Google Forms or the linked Sheet before sharing the site.

Keep the response Sheet restricted to the hosts. In Google Forms, give anyone with the link responder access and leave **View results summary** off. The page includes a link for guests who prefer to open the form in a new tab.

If the responder link asks for a Google sign-in, check the form’s settings before sharing. Turn off **Limit to 1 response**, choose **Do not collect** for email addresses if you do not need them, and check that there is no file-upload question or domain restriction. Test the responder link again while signed out.
